## Extracted build rules (max out)

### Systems over decoration

- Preset spacing, colours, type sizes (design system). Hours of discipline beat one-off “cool” pages.
- Micro text + large editorial content as a repeating balance (Acne).
- Easter eggs / console / 404 that still sell — every page earns its visit.
- Photography is the product: intentional backgrounds, shadows that feel tactile, model vs bare product as a deliberate choice.

### Homepage / index

- 20+ SKUs → do **not** dump every product on the homepage; categories or a sparse index first.
- Sticky brand mark / quiet nav that doesn’t compete with imagery.
- Featured single product beats a wall of cards when merch is the story (A24).

### PLP

- Sold-out state must be designed (overlay + clear label) — not a broken ATC.
- Sticky headers need readable contrast over changing imagery (gradient scrim beats opaque bars when photography leads).
- Side-scroll collections need visible controls for accessibility (On).
- Bottom sticky chrome on mobile (thumbs) is an emerging pattern worth using on PDP ATC.

### PDP

- Variant pickers as grids; bold single CTA; details in tabs/accordions — not text walls.
- Size guide as a **conversion tool** (compare brands, dynamic units, visuals that react to size) — not a static PDF.
- Price inside ATC can save mobile space when variants differ (Little Tokyo pattern).
- Gender toggle when imagery is unisex (On) reduces wrong-size friction.
- Dynamic story blocks (fit / materials / feel) justify price when content exists.

### Motion & interaction

- Prefer CSS for infinite loops and simple state flips; JS for multi-state choreography.
- Physical-feeling buttons (subtle shift / layered pseudo) beat glow effects.
- Sticky scroll storytelling only when it clarifies the product (Graza oil drop → logo).
- Menu cursor / click-outside affordances make dense nav feel obvious (On).

### Accessibility (do not copy the bad parts)

- Micro type below WCAG is an Acne aesthetic choice — Sable should not sacrifice readable body/CTA for cosplay.
- PDF menus break screen readers — keep commerce HTML.
- Contrast and hit targets on filters/ATC matter more than experimental density.

### Branding that converts

- Rename “blog” / utility surfaces with house language when it fits (Graza “Glog”).
- Humour and copy can be the brand (Cards Against Humanity) if it matches voice.
- Portfolio/studio sites: process + pricing transparency builds trust (Gardener) — useful for Sable Service tone.

## Map to Sable — eat the fish, spit the bones

Honest status after audit (2026-09-14). **Fully implementing every brand trick in the transcript is not the goal.** Only patterns that raise desire / clarity / conversion for a ~26-SKU house.

### Eaten (implemented)

| Pattern | Where |
|---------|--------|
| Sparse index before full catalogue (20+ rule) | `/` Index codes; commerce on `/shop` |
| Design tokens (spacing / colour / type presets) | `globals.css` |
| Micro label + clear product hierarchy | PLP + PDP |
| Variant grid + single bold CTA | PDP size grid + color-matched ATC |
| Details in accordions, not text walls | PDP Details / Fit / Shipping |
| Size guide as conversion (compare + units + pick) | Fit predictor modal |
| Price inside ATC (esp. mobile sticky) | Desktop ATC + sticky mobile bar |
| Designed sold-out / coming-soon state | Card overlay + Notify / Out of stock → waitlist |
| Sticky mobile buy chrome (thumb zone) | PDP sticky ATC |
| Sticky quiet header | Site header |
| Hover image swap / quick add | Shop PLP |
| SKIMS-style loading skeletons | Index, Shop, New, gender, archive, PDP |
| 404 that still sells | Product picks on `not-found` |
| Delayed mailing capture (not on entry) | 8s split modal |
| HTML commerce (not PDF menus) | Entire store |

### Spit (bones — do **not** build)

- Acne sticky mega-logo chasing scroll; illegible 12px body for “aesthetic”
- A24 grainy video heroes / immersive film world as homepage
- Graza lime checkerboard “physical” buttons + oil-drop scroll story
- Cards Against Humanity interactive game as landing
- Margiela clay masks / utopian tech UI cosplay / slow AI shop assistant as feature
- Cafe hand-drawn infinite spinners as decoration
- Full-page sideways PDP scroll without need
- Copying brand names, fonts, or colour systems
