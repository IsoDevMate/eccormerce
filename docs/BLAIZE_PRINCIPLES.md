# Blaize Smith principles (extracted — do not clone brands)

Source: local breakdown video *Yeezy vs Skims in web design* (Blaze Smith).  
Use these as **commercial constraints**, not as “make it look like Yeezy/Skims.”

## Small catalogue (&lt; ~50 SKUs)

- The **grid is the store**. Index (`/`) can be codes-only for desire; commerce lives one click away on `/shop` — still no marketing splash before product.
- Gender split = **instant filter / tab** on Index and Shop, not a separate splash.
- Less choice + fewer clicks → higher conversion.

## Merchandising

- Model shots beat flat lays when the garment matches the product.
- Featured video on a top-left / early grid cell helps scanning — **only with real garment footage** (never a random placeholder clip).
- Badges are rare (scarcity dies when everything is “Limited”).
- Filters earn their keep as catalogue size grows; don’t build an admin dashboard for 26 pieces. Prefer quiet text filters over thumbnail chrome.

## Conversion without screaming “BUY”

- Colour selection can theme the purchase control (swatch ↔ ATC).
- Delay email capture (~6–10s), don’t interrupt entry.
- Fit + shipping honesty on the PDP reduces anxiety (weeks to ship → say it).
- Skipping Apple Pay / Shop Pay on-product can keep people browsing (AOV tradeoff — deliberate).

## Brand value

- Perceived value comes from photography, hierarchy, naming, fit confidence — not beige + serif cosplay.
- Editorial interruptions create rhythm; they are not blog cards.
- Motion should feel restrained (image swap, drawer, filter), not decorative.

## Agent checklist

Ask of every screen:

1. Product discovery — fewer unnecessary clicks?
2. Product desire — does the grid make me want one piece?
3. Merchandising — right prominence / video / editorial beat?
4. Conversion — size, colour, ship, CTA clear?
5. AOV — natural next click, not spam upsells?
6. Friction — remove chrome that doesn’t sell or reassure?
